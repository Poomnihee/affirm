# 이달의 확언

달마다 정한 확언 다섯 문장을 기기 음성(TTS)으로 읽어 주고, 뒤에 배경음·주파수를 잔잔하게 깔아 주는 웹앱.

- 확언: 달별 5문장, 자동 저장(브라우저 localStorage), 재생 중 수정 반영
- 내 목소리: 문장별 녹음(앞뒤 무음 자동 정리) + 보정(차분하게·따뜻하게·잔향), AI 음성 파일 올리기
- 목소리: 시리 2번 → 시리 → 프리미엄 → 향상된 음성 순으로 자동 추천, 빠르기·음 높이·크기 조절
- 흐름: 문장 사이·바퀴 사이 간격(초), 반복 횟수 또는 무한 반복
- 배경음: 빗소리·파도·브라운/핑크 노이즈, 내 ASMR 파일 업로드(IndexedDB, 기기 안에만 저장)
- 주파수: 174/396/432/528Hz, 바이노럴 세타·알파·델타(이어폰)

빌드 없이 `index.html` 하나로 동작합니다. Vercel에 저장소를 연결하면 그대로 배포돼요(Framework: Other, 빌드 명령 없음).
